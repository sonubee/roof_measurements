Enter Home Address

Steps:

  1. Enter a US Residential Address
  2. This app will pull the Geocoordinates from Google Earth's API
  3. Then it will snap a Satellite image of the house with Google Map's API
  4. It will then infer a Instance Segmentation model I created on Roboflow to detect roof edges
  5. It will pull the actual roof square footage from Google Solar's API
  6. All of this information plus more is downloaded into a pdf

Notes:

  • Takes 30 secs to complete
  • Works on phones too
  • Currently detects all roof within image
  • Had another API giving Roof Type, but this is currently disabled for costs
